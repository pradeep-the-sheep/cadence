Cadence · Parkinson's Daily Companion

Cadence is a privacy-first, offline-first daily companion for Parkinson's self-management. It combines a 24-hour medication & symptom tracker, motor state logging, and an integrated exergame studio—featuring MediaPipe-powered Boxing, Pinch Dino, and LSVT-style Clock Reach games. It also includes voice therapy with real-time loudness feedback, rhythmic cueing for freezing of gait, and a local analytics engine that reveals correlations between lifestyle factors and symptoms.
